***My Projects and experiences*** : 

1. **MediRemind** · A lightweight, browser-based medicine reminder and real-time inventory tracker with offline support and cloud sync.
* **Problem**: Patients with chronic conditions or complex schedules often forget doses, and standard alarm apps fail to track remaining pill stock or dosage instructions.
* **What I Built**: A single-page web app featuring dynamic Neobrutalist prescription cards, automated inventory progress bars, low-stock threshold badges, and local-first persistence synced to a Supabase database.
* **Tech Stack**: HTML5, Vanilla CSS3, JavaScript (ES6+), Supabase (PostgreSQL), Lucide Icons.
* **My Role**: Full-stack developer handling core state management, UI design system implementation, and database architecture.


2. **Zynq** · A real-time operations engine designed to eliminate chaotic hackathon logistics.
* **Problem**: In-person hackathons struggle with manual check-in bottlenecks, uncoordinated volunteer shifts, static QR ticket fraud, and lost participants navigating large venues.
* **What I Built**: A multi-role platform featuring time-bucketed rotating QR badges, granular volunteer RBAC delegation, live hardware camera ticketing, an audio/haptic broadcast alert system, and a closed-loop help dispatcher.
* **Tech Stack**: Next.js/React, Node.js, MongoDB, Web Audio API, Tailwind CSS.
* **My Role**: Full-stack architect building security guards, real-time dispatch logic, and the administrative data console.


3. **AquaSense Pro** · An intelligent IoT-based water level, flow, and leak management system.
* **Problem**: Traditional water tanks suffer from dry-running motor burnout, undetected pipe leaks wasting thousands of litres, and manual monitoring hassles.
* **What I Built**: An automated controller featuring ultrasonic level sensing, differential flow leak detection, dry-run safety lockouts, non-blocking Wi-Fi fallback, and a smartphone telemetry dashboard.
* **Tech Stack**: ESP32, Arduino C++, HC-SR04, YF-S201 Flow Sensors, Blynk IoT Cloud, I2C LCD.
* **My Role**: Firmware engineer and hardware designer responsible for sensor data filtering, safety logic loops, and cloud integration.


4. **Verdantis** · A smart household bio-composting hardware and community waste-management system.
* **Problem**: Urban households generate massive amounts of organic kitchen waste that ends up in landfills, while traditional manual composting is slow, smelly, and pest-prone.
* **What I Built**: An odor-free, IoT-enabled countertop bio-composting unit utilizing microcontrollers, aerobic sensors, and bio-catalysts to accelerate waste breakdown from months down to days.
* **Tech Stack**: IoT Microcontrollers, Embedded Sensors, Aerobic Composting Hardware, Mobile App Interface.
* **My Role**: Conceptualizer and hardware-software integration lead focused on automated temperature/humidity control and system architecture.


5. **Sehha** · An AI-driven cognitive gaming and memory assistance platform tailored for elderly individuals.
* **Problem**: Elderly individuals experiencing memory decline lack engaging, safe, and accessible digital tools for daily cognitive stimulation and structured caregiver check-ins.
* **What I Built**: A web-based platform featuring adaptive memory-matching games, personalized daily reminders, a media-rich memory assistant, and a dedicated non-diagnostic caregiver activity dashboard.
* **Tech Stack**: React, Frontend UI/UX, AI/ML Personalization Layer, Secure Relational Database.
* **My Role**: Lead developer and designer focused on high-contrast accessibility standards, adaptive difficulty logic, and clean interface structures.
